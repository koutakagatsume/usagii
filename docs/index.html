01 リスト

予定がある日だけ、
まっすぐ。

空白の日は出しません。日付はスクロールで上に貼り付き、「今日」ボタンでいつでも現在へ。週・月表示にもワンタップで切り替え。

02 ピン留め

2ヶ月先の締切が、
ずっと見えてる。

ピン留めした予定は一覧の最上部に固定。「あと N 日」のカウントダウンで、遠い締切も見失いません。

03 カテゴリ

色で分けて、
ぱっと絞る。

予定には複数のカテゴリを付けられます。バッジをクリックすれば、その仲間だけにきゅっと絞り込み。

ダークに。

ライト・ダークの手動切替に加えて、OS の設定に合わせた自動切り替えにも対応しています。

FAQ

よくある質問。

本当に無料ですか?+

はい。フリーソフトとして公開しており、機能制限や課金はありません。

予定データはどこに保存されますか?+

すべてお使いの PC の中だけに保存されます。サーバはなく、外部に送信されることはありません。アカウント登録も不要です。

会社の PC で使えますか?+

外部通信を行わず、自動アップデートもありません。組織でお使いの際は、導入前に検証環境での動作確認をお願いします。実測で検証する手順も公開しています。

自動でアップデートされますか?+

いいえ。更新は、バージョンを指定したインストーラを手動で実行したときだけ。組織として許可するバージョンを固定できます。

対応している OS は?+

Windows 10 / 11(64bit)に対応しています。

起動時に警告が表示されます+

コード署名を行っていないため、初回実行時に SmartScreen の確認が表示されることがあります。配布元は GitHub の公開リポジトリのみです。

導入にあたって

セキュリティを最優先に。それでも、導入前の検証を。

usagii は、セキュリティ要件の厳しい企業環境でも使えることを目指して設計しています。外部との通信は一切行わず、予定データやテレメトリが PC の外へ送信されることはありません。これは宣言だけではなく、ご自身の環境で実測検証する手順を公開しています。

自動アップデート機構は意図的に搭載していません。更新はバージョンを指定したインストーラを手動で実行したときだけ。各バージョンのインストーラは Releases ページにすべて残ります。業務でお使いの際は、導入前に検証環境での評価を必ず実施してください。
