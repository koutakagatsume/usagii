リスト

予定がある日だけ、
時系列に。

空白の日は表示しません。日付はスクロールに合わせて上に貼り付き、「今日」ボタンでいつでも現在へ戻れます。もちろん、週・月のカレンダー表示にもワンタップで切り替えられます。

ピン留め

2ヶ月先の納品日が、
ずっと見えている。

ピン留めした予定は一覧の最上部に固定。「あと N 日」のカウントダウンで、遠い締切を見失いません。

カテゴリ

色で分けて、
一瞬で絞る。

予定には複数のカテゴリを付けられます。バッジをクリックすれば、その仲間だけに絞り込み。

テーマ

夜はダークテーマに。

ライト・ダークの手動切替に加えて、OS の設定に合わせた自動切り替えにも対応しています。

デモ

さわってみる。

インストールの前に、ブラウザでひと足だけ。タイトルを入れて登録、チェックで完了、ピンで固定。基本はこれだけです。

検索

ブラウザの中だけで動く簡易デモです。
入力した内容はどこにも保存及び送信されません。

呼べば、一瞬。トレイに常駐しているので、使いたいときにワンクリックですぐ開きます。起動を待つ時間はありません。
オフライン完結データはすべて PC の中だけに保存。外部への通信・送信は一切なく、アカウント登録も不要。あなたの予定が PC の外に出ることはありません。
更新もかんたん新しいバージョンはこのページから。インストーラを実行するだけで、予定データはそのまま引き継がれます。
ずっと無料フリーソフトとして公開しています。

プライバシー

あなたの予定は、
あなたの PC から出ない。

usagii にサーバはありません。予定・カテゴリ・設定はすべて手元の PC に保存され、開発者を含む誰かに送信されることはありません。

  • クラウド送信なし
  • アカウント不要
  • 外部への通信なし

プライバシー・免責事項 →

導入にあたって

セキュリティを最優先に。
それでも、導入前の検証を。

usagii は、セキュリティ要件の厳しい企業環境でも使えることを目指して設計しています。外部との通信は一切行わず、アカウント登録もなく、予定データやテレメトリが PC の外へ送信されることはありません。これは宣言だけではなく、ご自身の環境で実測検証する手順を公開しています(通信モニタでの確認、ファイアウォールで遮断したままの運用など)。

不具合の可能性は、usagii に限らずあらゆるソフトウェアにあるものです。そのうえで usagii は、セキュリティと品質の担保に最大限努め、継続的に改善を続けています。それでも業務でお使いいただく際は、導入前に検証環境での動作確認・評価を必ず実施してください。

自動アップデート機構は意図的に搭載していません。アプリが自動的に最新版へ置き換わることはなく、更新はバージョンを指定したインストーラを手動で実行したときだけ行われます。組織として許可するバージョンを固定し、配布や更新のタイミングを管理側で制御できます。各バージョンのインストーラは Releases ページにすべて残ります。

サポートポリシー: サポート対象は常に最新リリースです。不具合やセキュリティ上の問題が判明した場合は修正版を公開し、更新履歴でお知らせします。リリースは、依存ライブラリの既知脆弱性検査を通過したビルドのみを公開します。

※ コード署名を行っていないため、初回実行時に SmartScreen の確認が表示されることがあります(表示された場合の手順)。配布元は GitHub の公開リポジトリのみです。
