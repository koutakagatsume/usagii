プライバシーポリシー・免責事項

適用範囲

本文書は、Windows 向けデスクトップアプリ「usagii」および本サイト(usagii 公式ページ)に適用されます。

データの取り扱い

usagii は、予定・カテゴリ・設定を含むすべてのデータをお使いの PC 内にのみ保存します。開発者がユーザーのデータを収集・送信・閲覧することはありません。アカウント登録も不要です。

アプリの通信について

usagii は外部のサーバと通信しません。更新の確認や情報の送信を行う機能はなく、完全にオフラインで動作します。新しいバージョンへの更新は、本サイトまたは GitHub Releases から新しいインストーラをダウンロードして実行する手動方式です(予定データ・設定は引き継がれます)。

通信しないことをご自身の環境で検証する手順を公開しています: 外部に通信しないことの確認方法

本サイトについて

本サイトは GitHub Pages 上で提供されています。アクセス解析ツールや Cookie による追跡は使用していません。

初回起動時の SmartScreen 表示について

個人開発の署名なしアプリのため、初回実行時に「Windows によって PC が保護されました」という SmartScreen の確認が表示されることがあります。「詳細情報」→「実行」の順にクリックすると起動できます。インストーラの配布元は GitHub の公開リポジトリのみです。それ以外の場所で配布されているものはご利用にならないでください。

免責事項

usagii は現状有姿・無保証で提供されます。本ソフトウェアおよび本サイトの利用により生じたいかなる損害についても、開発者は責任を負いません。

本文書の変更

本文書の内容は予告なく変更されることがあります。変更後の内容は、本ページに掲載した時点で効力を生じます。
